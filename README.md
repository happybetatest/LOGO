# 🍯 LOGO Farm Macro - Tale Town (Honey Edition)

โปรแกรมมาโครฟาร์ม FiveM ทำงานเบื้องหลัง (Background Mode) ครบวงจร สำหรับเซิร์ฟเวอร์ TALE TOWN (ฟาร์มน้ำผึ้ง) พร้อมระบบสั่งการควบคุมระยะไกลผ่าน **Discord Bot**, ระบบนำทางปักหมุดแผนที่อัจฉริยะ, ระบบเบิกรถ และระบบขับรถอัตโนมัติ

---

## 🌟 คุณสมบัติเด่น (Key Features)

### 1. 🍯 ระบบฟาร์มและทิ้งน้ำผึ้งอัตโนมัติ (Honey Auto-Discard)
* 🟢 **Background Mode:** ทำงานเบื้องหลังได้โดยไม่ต้องดึงจอ FiveM มาบังหน้าจอหลัก
* 🍯 **ตรวจจับไอเทมน้ำผึ้งและจำนวน:** อ่านตัวเลขมุมขวาบนของช่องน้ำผึ้ง (X/60) ด้วยระบบ Digit OCR แม่นยำ 100%
* 🗑️ **ทิ้งน้ำผึ้งอัตโนมัติ:** เมื่อน้ำผึ้งถึงเป้าหมาย (สุ่มระหว่าง 20 - 40 ชิ้น) จะคลิกขวาที่ช่องน้ำผึ้ง ➔ กด Discard ➔ กดปุ่ม `↗↗` (ทั้งหมด) ➔ กดยืนยัน Discard และเริ่มฟาร์มต่ออัตโนมัติ
* 🍗 **ระบบกินข้าว/น้ำอัตโนมัติ (Auto-Feed):** ตรวจจับหลอดวงแหวนสีเหลือง (น่องไก่/ดาว) หรือกดช่อง 6 (น้ำ) และช่อง 7 (อาหาร) เมื่อค่าต่ำกว่าเกณฑ์

---

### 2. 🗺️ ระบบนำทางและปักหมุดแผนที่อัจฉริยะ (Map Navigation)
* **!map1 (จุดฟาร์ม):**
  * เปิดแผนที่ (P) ➔ เข้าสู่มุมมองแผนที่ (Enter)
  * สแกนตรวจจับแถบงานฟาร์ม ➔ กด Enter 1 ครั้งเพื่อปักหมุดม่วง Waypoint ➔ กด P ออกจากแผนที่ทันที
* **!map2 (พาวรถ Car Pound):**
  * เปิดแผนที่ (P) ➔ สแกนหา **Car Pound**
  * กดลูกศรขวา (Right Arrow) เพื่อสลับเป็น **❮ 2/2 ❯** ➔ ปักหมุด Waypoint อัตโนมัติ

---

### 3. 🚗 ระบบยานพาหนะและการเดินทาง (Vehicle Automation)
* **!car (เบิกรถอัตโนมัติ):** กดปุ่ม **E ค้าง 2.0 วินาที** ➔ เลือกการ์ดรถ ➔ คลิก **Select Vehicle** ➔ รอขึ้นรถ ➔ **รัดเข็มขัดนิรภัย (B)** 🔒
* **!drive (ขับรถอัตโนมัติ):** กดปุ่ม **- (หรือ ข)** ➔ คลิกปุ่ม **Auto Drive** ➔ **กด ESC ปิดเมนู** ทันที

| คำสั่ง (Prefix เริ่มต้นคือ !) | คำสั่งย่อ / ภาษาไทย | รายละเอียดการทำงาน |
| :--- | :--- | :--- |

| **!เข้าเกม [IP/cfx]** | !connect, !join | สั่งเปิด FiveM และเชื่อมต่อเข้าเซิร์ฟเวอร์ทันที |
| **!map1** | !mark1, !มาร์ค1 | ปักหมุด Waypoint ไปยังจุดฟาร์ม |
| **!map2** | !mark2, !พาวรถ | ปักหมุด Waypoint ไปยังพาวรถ (Car Pound 2/2 🚗) |
| **!car** | !เบิกรถ, !spawn | เปิดการาจ (E ค้าง 2วิ) ➔ เลือกรถ ➔ เบิกรถ ➔ รัดเข็มขัด (B) |
| **!drive** | !ขับออโต้, !autodrive | กด - (ข) ➔ คลิกเปิด Auto Drive ➔ กด ESC ปิดเมนู |
| **!check** | !bag, !กระเป๋า, !น้ำผึ้ง | เปิดกระเป๋า ตรวจเช็คน้ำผึ้ง และถ่ายรูปส่งกลับมา |
| **!close** | !t, !ปิดกระเป๋า, !ปิด | สั่งกดปุ่ม T เพื่อปิดกระเป๋าทันที |
| **!discard** | !ทิ้งน้ำผึ้ง, !ทิ้ง | สั่งทิ้งน้ำผึ้ง กดยืนยัน และกลับไปเริ่มฟาร์มต่อให้อัตโนมัติ |
| **!screen** | !จอ, !ภาพ | ถ่ายภาพหน้าจอ FiveM สดๆ ส่งกลับมาในห้องแชท |
| **!status** | !สถานะ | ตรวจสอบสถานะการทำงาน, น้ำ/อาหาร, เป้าหมายทิ้งน้ำผึ้ง |
| **!start** | !เริ่ม | สั่งเริ่มการทำงานของมาโคร (เทียบเท่าปุ่ม F9) |
| **!stop** | !หยุด | สั่งหยุดพักมาโครชั่วคราว (เทียบเท่าปุ่ม F9) |
| **!feed** | !กินข้าว | สั่งให้ตัวละครกินน้ำ (ช่อง 6) และอาหาร (ช่อง 7) ทันที |

## ⌨️ คีย์ลัดหลัก (Hotkeys)

* **F9**: เริ่ม / หยุดการทำงานของมาโครฟาร์ม
* **P**: เปิด / ปิด แผนที่ (Pause Menu Map)
* **- (ข)**: เปิดเมนูควบคุมยานพาหนะ (Vehicle Control)
* **E (ค้าง 2.0s)**: เปิดเมนูเบิกรถการาจ
* **B**: รัด / ปลด เข็มขัดนิรภัย

---

## 🚀 การเปิดใช้งาน

1. เปิดใช้งาน **FiveM** และเชื่อมต่อเข้าเซิร์ฟเวอร์
2. ดับเบิ้ลคลิกไฟล์ **`เปิดมาโคร_LOGO.bat`** บนหน้าจอ Desktop (หรือ **`LOGO-Launcher.exe`**)
3. โปรแกรมจะตรวจจับหน้าต่างเกม FiveM อัตโนมัติ (ไฟสถานะขึ้นสีเขียว 🟢)
4. ปรับแต่งการตั้งค่าที่ต้องการ หรือกด **F9** เพื่อเริ่มฟาร์มได้ทันที
